# CD-RW/DVD-RW SCSI Command Plan for rwemu

## Background

rwemu currently implements USB Mass Storage Class (MSC) with SCSI Transparent (sub-class 0x06, protocol 0x50). For CD-RW/DVD-RW emulation, the device must report as an optical drive and support different SCSI commands.

---

### rwemu_scsi.c

1. **`SCSI_WRITE_10 (0x2A)`** — Mass storage write command; not used by CD-ROM devices for read-only emulation.

## Commands to Stub / Add

### rwemu_scsi.c

3. **`SCSI_READ_CAPACITY_10 (0x25)`** — Not valid for CD-ROM devices; should return ILLEGAL REQUEST.
   - Keep the `#define` at line 11
   - Lines 171-186: comment out case handler in `scsi_cmd_tx_data()`
   - Line 234: remove from `scsi_cmd_end()` switch (default case already returns false with error)

4. **`SCSI_READ_TOC_PMA_ATIP (0x43)`** — Table of Contents / Program Memory Area / ATIP; Windows needs this to enumerate disc contents.
   - Add `#define SCSI_READ_TOC (0x43)` at top of file
   - Stub in `scsi_cmd_start()`: parse parameters from byte [1] (format) and [8-9] (start LBA) — minimal parsing, just store for tx
   - Stub in `scsi_cmd_tx_data()`: return a minimal TOC response (2 bytes header + session data ~18 bytes) — hardcode single session at LBA 0
   - Stub in `scsi_cmd_end()`: return tx_done status

5. **`SCSI_READ_CD (0xBE)`** — Variable sector size read with sub-channel data; used by some OSes for CD-DA or special formats.
   - Add `#define SCSI_READ_CD (0xBE)` at top of file
   - Stub in `scsi_cmd_start()`: parse LBA/count from bytes [2-5] and [7-8] — reuse `read_10` struct
   - Stub in `scsi_cmd_tx_data()`: copy current READ_10 implementation (lines 199-211), ignore sub-channel request
   - Stub in `scsi_cmd_end()`: add to the `return scsi->tx_done;` group on line 236

6. **`SCSI_READ_DISC_INFORMATION (0x51)`** — Returns disc type, media status, copyright info.
   - Add `#define SCSI_READ_DISC_INFO (0x51)` at top of file
   - Stub in `scsi_cmd_start()`: parse byte [1] (session info) and [2-3] (current LBA) — minimal parsing
   - Stub in `scsi_cmd_tx_data()`: return 8-byte response (disc type = 0x00 blank, session info = 0x01, current LBA from parsed value)
   - Stub in `scsi_cmd_end()`: return tx_done status

7. **`SCSI_GET_CONFIGURATION (0x46)`** — Reports device capabilities; Windows uses this to detect optical drives.
   - Add `#define SCSI_GET_CONFIG (0x46)` at top of file
   - Stub in `scsi_cmd_start()`: parse byte [1] (capability mask) and [2-5] (current position) — minimal parsing
   - Stub in `scsi_cmd_tx_data()`: return ~8-byte response with capability bit 0x04 set (read CD/DVD), plus descriptive text "CD-RW/DVD-RW Emu"
   - Stub in `scsi_cmd_end()`: return tx_done status

8. **`SCSI_READ_TRACK_INFORMATION (0x52)`** — Returns track boundaries and data types; used for multi-session discs.
   - Add `#define SCSI_READ_TRACK_INFO (0x52)` at top of file
   - Stub in `scsi_cmd_start()`: parse byte [1] (track number, 0x00 = all tracks) — minimal parsing
   - Stub in `scsi_cmd_tx_data()`: return ~10-byte response with single track starting at LBA 0, data format = 0x04 (Mode 1/2)
   - Stub in `scsi_cmd_end()`: return tx_done status

9. **`SCSI_READ_DVD_STRUCTURE (0xAD)`** — DVD-specific structure info (ROM, R, RW variants).
   - Add `#define SCSI_READ_DVD_STRUCT (0xAD)` at top of file
   - Stub in `scsi_cmd_start()`: parse byte [2] (structure type), [3] (page control), [8-9] (start LBA) — minimal parsing
   - Stub in `scsi_cmd_tx_data()`: return DVD-ROM structure page (type 0x00, ~24 bytes with manufacturer/layer info)
   - Stub in `scsi_cmd_end()`: return tx_done status

10. **`SCSI_READ_12 (0xA8)`** — 12-byte READ command; used by some OSes for optical drives instead of READ_10.
    - Add `#define SCSI_READ_12 (0xA8)` at top of file
    - Stub in `scsi_cmd_start()`: parse LBA from bytes [2-5] and count from [6-9] — reuse `read_10` struct (LBA same, count is 3-byte field)
    - Stub in `scsi_cmd_tx_data()`: copy current READ_10 implementation (lines 199-211), just change case label to `SCSI_READ_12`
    - Stub in `scsi_cmd_end()`: add to the `return scsi->tx_done;` group on line 236

11. **`SCSI_FORMAT_UNIT (0x04)`** — Formats media; CD-RW is auto-formatted by host, so stub as error.
    - Add `#define SCSI_FORMAT_UNIT (0x04)` at top of file
    - No case handlers needed; default case returns ILLEGAL REQUEST

12. **`SCSI_BLANK (0xA1)`** — Blanks a CD-R/RW disc for re-use; stub as error for read-only mode.
    - Add `#define SCSI_BLANK (0xA1)` at top of file
    - No case handlers needed; default case returns ILLEGAL REQUEST

## USB Descriptor Changes (rwemu_usb.c)

7. **USB class/subclass/protocol** — Change from MSC to CD-ROM:
   ```c
   // Current (MSC):
   .bInterfaceClass = USB_CLASS_MASS_STORAGE,      // 0x08
   .bInterfaceSubClass = 0x06,                      // SCSI transparent
   .bInterfaceProtocol = 0x50,                      // Bulk-Only

   // New (CD-ROM):
   .bInterfaceClass = 0x0B,                         // CD/DVD
   .bInterfaceSubClass = 0x0A,                      // SFF-8020i / MMC
   .bInterfaceProtocol = 0x00,                      // No protocol
   ```

## SCSI Inquiry Response Changes (rwemu_scsi.c)

8. **INQUIRY device type byte** — Change from direct-access block device to CD-ROM:
   ```c
   // Current:
   data[0] = 0x00; // device type: direct access block device

   // New:
   data[0] = 0x05; // device type: CD/DVD
   ```

9. **INQUIRY version/response fields** — Consider updating for MMC compliance:
   - `data[2]` (version): keep as 0x04 or change to 0x05 for MMC-5
   - `data[3]` (response data format): keep as 0x02

## Implementation Task List

1. **rwemu_scsi.h**: Comment out `SCSI_WRITE_10` define (line 16); comment out `write_10` struct in union (lines 46-49)
2. **rwemu_scsi.c**: Remove all WRITE_10 case handlers from start/rx/end/tx functions (lines 30-36, 52-63, 228)
3. **rwemu_scsi.c**: Comment out READ_CAPACITY_10 case in tx_data (lines 171-186) and end (line 234)
4. **rwemu_scsi.c**: Add defines for all new commands (0x04, 0x43, 0x46, 0x51, 0x52, 0xAD, 0xA1, 0xA8, 0xBE); add start() parsing + tx_data stubs for TOC/CONFIG/DISC_INFO/TRACK_INFO/DVD_STRUCT; copy READ_10 logic for READ_CD and READ_12
5. **rwemu_usb.c**: Change USB descriptor class/subclass/protocol from 0x08/0x06/0x50 to 0x0B/0x0A/0x00 (lines 412-414)
6. **rwemu_scsi.c**: Change INQUIRY device type byte from 0x00 to 0x05 (line 116)

## Decisions Made

1. **WRITE_12 / FORMAT_UNIT / BLANK stubbing**: Return ILLEGAL REQUEST via default case — no write forwarding needed for read-only CD-ROM mode
2. **READ_CD vs READ_10**: Both coexist; READ_10 kept as fallback, READ_CD (0xBE) added with same logic but ignoring sub-channel data
3. **INQUIRY version byte**: Keep at 0x04 (SDMMC-2) — sufficient for basic CD-ROM enumeration; MMC-5 update can be done later
4. **TOC response format**: Hardcode single session starting at LBA 0, first track at LBA 1 — covers most ISO 9660 discs
5. **GET_CONFIGURATION**: Return capability bit 0x04 (read CD/DVD) plus descriptive text; omits write-related bits for read-only mode
